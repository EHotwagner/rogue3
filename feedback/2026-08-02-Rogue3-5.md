## §4 Findings

#### §4.1 The game scaffold ships adapt-me helper modules compiled by default and nothing reports the ones you never adopt

- **Kind:** quality-gap
- **Impact:** Every generated `game`/`sample-pack` product carries unreachable compile weight for its whole life unless a human happens to audit for it. At `1f19809` that was **531 lines across three modules** — `Grids.fs` 176, `LineDrawing.fs` 106, `Visibility.fs` 249 — undetected from scaffold time through twelve milestones. This cycle removed the first two; the third is #28.
- **Expected:** Either the helper set is opt-in at scaffold time, or the product's own gate surfaces "these `Exists`-guarded compile items are referenced by nothing" — the same class of signal the compile-order and template-drift gates already provide.
- **Observed:** `Rogue3.fsproj` carries **six** `Exists`-guarded compile items (`Vec2.fs`, `Collision.fs`, `Visibility.fs`, `GameShell.fs`, `Grids.fs`, `LineDrawing.fs`). Of the four scaffold geometry/simulation helpers, exactly **one** was adopted: `Collision.fs`, with two call sites (`Model.fs:1081`, `Model.fs:1650`). `Grids.fs`, `LineDrawing.fs` and `Visibility.fs` had zero code references from game code, the evidence modules, or the tests. The full `Verify` gate — Dev, GeneratedGuidanceCheck, TemplateDrift, Test, PerformanceIntent, PerformanceEvidence — passes green over all of it without a word; the gate's silence is the finding, and no command in the workspace surfaces the gap, which is itself the point. Non-adoption was structural: the simulation is continuous-space (`Collision.sweepCircle` over `Rect` room bounds and `Vec2` obstacles, `Model.fs:1650`), and every `Cell` value in the product is a room-graph coordinate from `FloorGeneration.fs` consumed by `Render.fs:93` and `Model.fs:1369` — none of which wants the edges/corners between cells or a sight-line through them. `GameShell.fs` was not audited.
- **Evidence:** file:src/Rogue3/Rogue3.fsproj; file:src/Rogue3/Visibility.fs; issue:EHotwagner/rogue3#19; issue:EHotwagner/rogue3#28; command:dotnet test Rogue3.slnx
- **Version:** scaffold generator FS.GG.SDD.Artifacts 0.32.0, provider contract 1.1.0, template `fs-gg-ui`, profile `game`. Not re-verified against a newer generator; none available in this workspace.
- **Owner:** FS-GG scaffold provider — the `game`/`sample-pack` template helper set and the generated `Product.fsproj` compile items.
- **Recurrence:** new for helper *modules*.
