- **Kind:** defect
- **Impact:** My own candidate, caught before review. Replacing

- **Observed:** The two orders differ wherever a directory and a file share a prefix:

## §7 Workarounds still in the tree

- `kitTreeFiles` is retained as a thin wrapper that discards `kitTreeScan`'s problem lines, because

  calls. A future caller that wants the enumeration can therefore drop the refusals silently. The
  mitigation is a doc comment saying so and the fact that every violation-producing caller uses
  `kitTreeScan` directly; that is weaker than making it unconstructible, which is the standard this
