#### §4.4 A fault-injection probe whose plant is recognisable becomes the exemption predicate it was built to kill

- **Impact:** Two successive implementations of #74's fix were themselves single-edit-defeatable, in
  a way that would have read as closed to anyone who only ran the fingerprint mutants. This is the
  finding most worth carrying to other repositories: it generalises to any self-test that injects a
  fault.
- **Expected:** A positive control that plants a real violation in the real tree closes the class,
  because the tree under test is the repository.
- **Observed:** It closes fingerprints **of the repository**. It leaves fingerprints **of the plant**,
  and a plant is recognisable by anything constant about it:
  - *A literal.* The first version appended a self-describing comment naming the probe, so a killed
    run left something legible. `File.Exists slnx && not (<any kit file contains that marker>)` is
    one line, and gave exit 0, `verdict: pass`, with real drift on disk.
  - *A structure.* Replacing the marker with "append the file to itself" removed the literal and left
    a shape. `File.Exists slnx && (<the probed file is NOT its own bytes twice>) then [] else` is one
    line, and is a defeat in turn: **exit 0**, `166 case(s), 0 failure(s)`, `verdict: pass`, with real
    drift on disk.
    That doubling implementation was never committed, so this was author testimony when first
    written. It is now measured. The shipped plant is turned back into the doubling plant by ONE
    substitution in `templateDriftBindingProbe` — `let junk = Guid.NewGuid().ToByteArray()` becomes
    `let junk = File.ReadAllBytes stash` — and the reconstruction is exercised three ways: the
    doubling probe with no exemption is green (exit 0), which establishes it is a working probe and
    not a broken one; doubling plus the structure-detecting exemption plus real drift is **exit 0**,
    the defeat; and that same exemption against the SHIPPED arbitrary plant is exit 1.
  - The mutant is not asking "is this the repository"; it is asking "is the probe in flight", and it
    checks honestly while it is. The only version that holds is a plant with nothing constant about
    it — 16 GUID bytes, a bare-GUID directory — after which the sole discriminator left is the
    violation itself, and a mutant that keys on *that* checks honestly exactly when it matters.
  - Both mutants exit 1 against the shipped version.
- **Evidence:** command:./fake.sh -t SelfTest with the exemption `File.Exists Rogue3.slnx && not (any kit file contains the marker)` — exit 0 against branch commit e21dc2c (the marker plant), exit 1 against the branch head; command:./fake.sh -t SelfTest against the branch head with `let junk = Guid.NewGuid().ToByteArray()` replaced by `let junk = File.ReadAllBytes stash` in templateDriftBindingProbe — exit 0 with no exemption (the doubling probe works), exit 0 with the exemption `File.Exists Rogue3.slnx && (the probed file is NOT its own bytes twice) then [] else` plus real drift (the defeat), and exit 1 for that same exemption against the unmodified branch head; file:build.fsx

- **Owner:** FS-GG/fs-gg-testing — state it as a rule wherever self-test fault injection is
